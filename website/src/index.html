See beyond the changed repo.

Billing changed its contract, and nobody declared the link to web. No requirements written. Lemma read the call in web’s code and saw it breaks.

That gives the agent a focused path through a large codebase: what depends on the change and where the relevant code lives.

Declared requirements ↗

Simulate the failure. Verify the fix.

A contract can stay the same while behavior breaks. Here, Billing returns a retry flag that Orders must pass through, so the caller knows how to respond to a failed payment.

replay_declined_charge is a checker you declare: any command that runs your code and reports what it saw. through: link names the call it stands in for, and need asks it for evidence, once for each case. Lemma keeps that evidence until the code it rests on changes.

Compare Before and After to see both cases. The agent gets the failing value to correct, then reruns the check.Illustrative replay · evidence tied to the checked revision.
